1. Emisor

Recomendado: Grid 56 + Adaptive Color 4-bit + Turbo. La cuadrícula física vuelve exactamente a 12%–88%, igual que el decoder; el aislamiento se obtiene con tags binarios y Stage Card, no desplazando DATA.

Cambio radical: cada esquina transmite un ID binario distinto. Una celda DATA, aunque sea negra o del mismo color que antes usábamos en el marco, no puede convertirse en TL/TR/BL/BR.
Geometría única: emisor y receptor usan exactamente DATA_MIN=.12 / DATA_MAX=.88. Se eliminó el desacople visual 15% vs decoder 12%.
Inicio: HELLO → Color Training → primer DATA fijo → secuencia → PASS_END/NACK/Repair.

2. Receptor / Binary Tag Lock

El receptor busca patrones 7×7 blanco/negro con código interno 5×5. Cada patrón tiene ID y distancia de Hamming propia. Solo después de identificar las esquinas calcula la homografía.
