1. Emisor

Perfil recomendado: Grid 56 + Stable Color 3-bit + Premium 12 img/s. No subimos fps: aumentamos bytes útiles por imagen y reducimos errores causados por transición de pantalla, blur y mezcla entre celdas.

Closing Burst real: el primer NACK es necesario para decirle al emisor qué bloques faltan. Si quedan 1–500, después de leer ese NACK se hacen 3 ciclos internos: normal → invertido → intercalado. Solo entonces vuelve PASS_END.
Más datos sin más fps: el bloque lógico sube de 360 a 372 B, prácticamente el máximo para 3 bloques por imagen en Grid 56/3-bit.
Micro Cell Guard: cada celda color tiene un núcleo cromático y un borde gris fino para reducir contaminación por movimiento/desenfoque entre celdas vecinas.
VSync: los cambios de imagen se hacen alineados al repaint del display en vez de un temporizador arbitrario.

2. Receptor / Binary Tag Lock

HPS7 usa directamente las coordenadas de los tags binarios para la homografía y muestrea cada celda con una mediana de 5 puntos. La telemetría distingue estabilidad óptica, movimiento y temblor.
