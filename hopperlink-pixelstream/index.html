Proyección HPS7: después de preparar el archivo aparece una tabla 2/3/4-bit con bloques por stream físico, cantidad de streams DATA, cadencia y tiempo perfecto estimado.
Vertical DualLane: arriba y abajo llevan paquetes HPS7 distintos pero cada lane conserva su grid completo. Los cuatro tags exteriores delimitan un stage 1:2.
Clean Repair Target: al leer un NACK aparece el patrón estático sin barra superior, metadatos, Cancelar ni botones sobre el stream. Solo queda un botón inferior fuera del área óptica para iniciar el Repair cuando el receptor ya tenga LOCK.
Repetición dinámica: n = floor(1500 / faltantes), con mínimo 1. Ej.: 499→3, 290→5, 100→15, 50→30. No se pide NACK entre los n ciclos internos.
Controles: HELLO, PASS_END, NACK y COMPLETE siguen usando el stage cuadrado robusto. Solo DATA/Repair se expande a DualLane.
