Detalles técnicos y diagnóstico
Optical Dock v2: borde negro/blanco grueso + 4 Binary Tags + 4 anclas laterales + rails fotométricos. El DATA sigue intacto dentro de 12%-88%.
Contour Lock: si una esquina/tag se pierde, el receptor puede reconstruir la geometría desde el gran rectángulo y la proporción del stage.
Stable Frame Gate: durante cambios de stream, rolling shutter o temblor fuerte se reutiliza brevemente el último frame estable; los duplicados se ignoran y se evitan CRC falsos.
Photometric Rails: referencias superior/inferior para medir contraste, clipping y desigualdad de iluminación sin ocupar celdas DATA.
Repair dinámico: n = floor(1500 / faltantes), mínimo 1. Los ciclos alternan orden y posición de lanes.
