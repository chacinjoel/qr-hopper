Detalles técnicos y reglas
DualLane: cada mitad conserva un grid completo. La densidad se expresa siempre como bloques/lane × lanes = bloques/stream físico.
Repair Target: no contiene DATA válido. Mantén el patrón hasta que el receptor muestre TAGS 4/4 / LOCK.
Repair dinámico: n = floor(1500 / faltantes), mínimo 1. Los ciclos alternan orden y posición de lanes para reducir errores sistemáticos.
Finalizar ronda: durante un Repair puedes terminar los ciclos restantes si el receptor ya muestra 0 faltantes.
