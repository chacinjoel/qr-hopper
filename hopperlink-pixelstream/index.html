1. Emisor

DualLane mantiene exactamente el grid 56×56 ya probado en cada mitad. No aumenta la frecuencia ni reduce el tamaño de celda: envía dos paquetes simultáneos usando la altura de la pantalla.

Vertical DualLane: arriba y abajo llevan paquetes HPS7 distintos pero cada lane conserva 56×56, sus pilotos y el mismo tamaño físico de celda. Los cuatro tags exteriores delimitan un stage 1:2.
Controles: HELLO, PASS_END, NACK y COMPLETE siguen usando el stage cuadrado robusto. Solo DATA/Repair se expande a DualLane.
Closing Burst obligatorio: con 1–500 faltantes se hacen 3 ciclos seguidos normal → invertido → intercalado, sin NACK intermedio.
Objetivo: si la tasa de aceptación se mantiene, DualLane puede acercarse a reducir casi a la mitad el tiempo frente a Square con la misma modulación.

2. Receptor / Binary Tag Lock

El receptor puede decodificar los dos lanes de una misma captura. El detector de tags reutiliza geometría validada cuando está estable para liberar CPU a los dos decoders DATA.
